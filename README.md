# Open-Source Intelligence (OSINT): 5-Day Programme

This workbook accompanies the five-day, in-person OSINT programme. It holds the reading for every session and the step-by-step instructions for every lab.

## How to use this workbook

- **Before the course**, read the pre-reading pack and check that your laptop meets the joining instructions.
- **During the course**, open the lab page at the start of each lab. Every lab states its aim and outcome at the top, then numbered steps, then a summary.
- **After the course**, the session pages are your reference. They are written to be read on their own.

## Ground rules that apply to every lab

1. All labs run against instructor-provided sandbox targets, synthetic personas, public-domain subjects or your own organisation within agreed scope.
2. No exercise is conducted against a private individual or a third-party system without authorisation.
3. If a step would require you to log in to something you were not given credentials for, guess a password, or interact with a real person, stop and ask the instructor.
4. Work only inside your research VM from Lab 1.4 onwards.

## The running case

From Lab 1.1 to the capstone you work one investigation for one fictional client. Labs marked **Running case** add to the same case file. Keep it up to date: the capstone assumes you have it.
